# Estrutura do projeto

- `screens/` — uma tela por arquivo (Home, Search, Library, PlaylistDetail, Player, Profile)
- `components/` — componentes reutilizáveis (SongItem, MiniPlayer, etc.)
- `navigation/` — configuração das rotas (tabs + stack)
- `constants/` — cores, tipografia e espaçamentos do app (tema)
- `data/` — dados mockados (músicas, playlists, álbuns)
